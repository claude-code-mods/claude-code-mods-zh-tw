# multi-core

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。原版 README 見 [README.en.md](README.en.md)。

在一個 Claude Code 會話中使用 ChatGPT (Codex)、Cursor、OpenCode Zen 與 Antigravity 模型。用 `/model` 切換，委派給命名的原生 worker，並保留每個提供方自己的登入與許可權。

## 安裝

```
/plugin install multi-core@claude-code-mods-zh
```
