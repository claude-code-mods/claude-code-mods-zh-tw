# Codex Attachment Manager（暫定）

> **狀態：已被 [docs/spec.md](../../spec.md) 取代（2026-09-24）。** 本檔案保留作為最初構想的記錄，不再作為依據。

## 一句話目標

在 Codex 桌面視窗旁提供一個視覺化附件面板，讓使用者逐輪決定哪些歷史圖片、音訊、影片和檔案進入下一次模型請求。所有原始檔案及聊天記錄留在本地；取消勾選只改變下一輪發送的內容，不刪除檔案或聊天曆史。

## 使用者場景

使用者先上傳參考圖 A，Codex 生成圖片 B，隨後使用者再次引用 B 請求修改。面板應按聊天時間順序顯示 A、B 及 B 再次出現的記錄。使用者可以取消勾選 A，保留 B；B 的再次出現應指向同一份素材，不再作為另一份圖片傳送。廢稿仍可在面板中回看，需要時重新勾選。

## 核心概念與規則

- **素材**：一份可讀取的本地媒體或附件，具有穩定的 `asset_id`、型別、原始路徑、內容雜湊和來源。原始檔案保持不變。
- **出現記錄**：素材在上傳、生成、引用或工具結果中出現的一次事件。多條記錄可以指向同一份素材；不能把“聊天裡出現幾次”當成“有幾個不同檔案”。
- **本輪選擇集**：使用者在面板裡勾選、允許進入下一次請求的素材。選擇狀態按素材管理；每輪發送前都可調整。
- **精確重複**：內容雜湊相同的記錄歸到同一素材。重新編碼但畫面相同的圖片可提示使用者確認；有實際修改的版本保留為另一素材，並記錄版本關係。
- **未勾選的重複記錄**：只發送短文字引用，例如 `記錄 #12 與 IMG-004 為同一素材；本記錄沒有額外影像內容`。如果 IMG-004 本輪被勾選，它的影像內容只發送一次；如果也未勾選，則兩條記錄都只有文字佔位。
- **未勾選的獨立素材**：只發送短文字佔位，例如 `IMG-001：本輪未提供影像內容；不能據此判斷畫面細節`。不傳送其媒體位元組，也不在佔位符中暴露可被誤讀為已提供內容的路徑。
- **已勾選素材**：在本輪輸入裡附上實際內容，並在文字索引中用 `asset_id` 指向它。面板必須同時顯示“文字索引”和“實際附帶的檔案”。

## 介面形態

第一版面向 Windows Codex 桌面版。一個獨立的小按鈕貼在 Codex 視窗右側，隨視窗移動、縮放、最小化和恢復；點選後展開可滾動的附件時間線。每條記錄展示縮圖或檔案圖示、所在輪次、來源、檔案大小、重複/版本關係和本輪勾選狀態。面板提供“本輪將傳送什麼”預覽，明確區分實際媒體內容、重複引用和獨立佔位符。視窗最大化或貼近螢幕邊緣時，面板自動改到可見位置。

## 實現邊界與路線

Codex 現有公開外掛介面不能逐項改寫原生任務中已經存在的模型歷史。僅在舊任務旁顯示勾選框，無法保證舊圖片從它下一次原生請求中消失；也不能透過修改本地聊天記錄檔案來冒充請求管理。

因此第一版分兩層：

1. **只讀匯入與素材索引**：從可用的任務介面及本地素材位置識別歷史附件，建立自己的索引和縮圖。舊聊天記錄與原檔案只讀，不移動、不刪除。
2. **受控的後續請求**：面板維持一個對使用者連續的“創作專案”；底層在需要控制上下文時建立乾淨的 Codex 後續任務，只交接必要文字摘要、素材索引和本輪勾選的附件。生成和檢視媒體的受控工具應把完整媒體儲存在本地，給 Codex 返回簡短 ID/路徑說明，避免把大塊圖片資料寫進工具結果。

這意味著可以實現使用者感受到的連續多輪創作，但不能承諾同一個原生 Codex 任務 ID 在不變的情況下任意剔除舊圖片。面板中必須明確標示當前操作是“只讀預覽”還是“受控傳送”。

## 第一輪驗證

用已經出現斷連的任務作**只讀樣本**，不打斷或修改它：

1. 展示該任務能識別到的素材時間線、精確重複項和無法識別的專案；允許使用者勾選。
2. 同屏展示兩種未勾選記錄的模型可見文字、實際選擇的媒體清單，以及各項預計傳送位元組數。預覽不得被描述成已經發出的網路請求。
3. 使用受控的乾淨後續任務傳送選中素材，記錄實際請求在壓縮前後的大小、連線錯誤和完成情況；與舊任務的只讀基線比較。
4. 驗證原始素材檔案和舊任務記錄在操作前後沒有被刪除或改寫。

2026-09-24 的初步只讀檢查：原任務記錄中可識別到 10 份不同的內聯圖片內容；fork 中可識別到的 4 張圖片均能與原任務的圖片匹配。該 fork 近期再次出現 WebSocket 斷流，後續 HTTP 請求約為 43.8 MB（壓縮前）。這些數字只描述已檢查到的記錄和請求，不代表任務裡全部可能存在的本地附件，也不證明圖片大小是斷連的唯一原因。

## 首版範圍

先做圖片的完整流程：匯入、時間線、精確去重、勾選、兩種佔位符、受控傳送和前後請求大小展示。素材模型預留 MIME 型別和通用檔案元資料，音訊、影片及其他附件在圖片流程驗證後接入。
