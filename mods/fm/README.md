# Firstmate Calm

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。

Firstmate Calm 為 Claude Code 帶來帆船工作動畫與會話專用轉錄展示，並與 Pi Calm 擴充套件共享每個 home 的 calm 偏好。

其 hooks 模組可透過 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` 或 Claude Code 的 tengu_plugin_hooks_modules 灰度開關載入，但僅當 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` 恰為 1 時才會生效，其餘情況下完全不執行任何操作。

## 安裝

```
/plugin install fm@claude-code-mods-zh
```
