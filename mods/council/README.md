# claude-council

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。原版 README 見 [README.en.md](README.en.md)。

同時諮詢多個 AI agent（Gemini、OpenAI、Grok、Perplexity、Kimi、OpenRouter 路由的任意模型，以及已安裝的 codex、antigravity、grok、kimi、cursor CLI 和本地 ollama 模型），以獲得對程式設計問題的多元視角。提供 tmux 或 Claude Code 內的流式面板；開啟後還會在你的提示行上方顯示一行額外複查提示。

## 安裝

```
/plugin marketplace add hex/claude-council
/plugin install claude-council@claude-council
```
