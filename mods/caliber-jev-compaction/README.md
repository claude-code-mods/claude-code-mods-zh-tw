# caliber-jev-compaction

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。

為 Claude Code 會話提供逐字保留的 Jev 壓縮。

## 安裝

```
/plugin install caliber-jev-compaction@claude-code-mods-zh
```

安裝後可在外掛配置中填寫自己的 TypeSafe API key。
