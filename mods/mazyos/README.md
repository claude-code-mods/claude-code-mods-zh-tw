# MazyOS

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。原版 README 見 [README.en.md](README.en.md)。

葡語商業作業系統外掛：每次會話都帶入你的公司記憶、輸出帶品牌視覺，並提供 17 個營銷、SEO、Google Ads、Instagram 輪播與 Google Maps 客戶開發技能。聊天旁有面板、提示行上方有狀態條，並在破壞性 git 命令前設閘。

## 安裝

```
/plugin install mazyos@claude-code-mods-zh
```
