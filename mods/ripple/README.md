# ripple

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。原版 README 見 [README.en.md](README.en.md)。

為每條提示選擇推理強度、為每個委派任務選擇 worker，可保持提示詞快取溫熱，並顯示 ClaudeRipple 把每個請求發往何處。

## 安裝

```
/plugin install ripple@claude-code-mods-zh
```
