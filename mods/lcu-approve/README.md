# lcu-approve

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。

為 Claude 應用與 Claude Code 中的 LCU 電腦操作提供按應用的原生授權（本次允許、始終允許、拒絕），並提供 `/computer-use-apps` 已授權應用面板。

## 安裝

```
/plugin install lcu-approve@claude-code-mods-zh
```
