# TavernWeaveX

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。原版 README 見 [README.en.md](README.en.md)。

23 個共享技能，用於角色卡、軟體工作與有界的雲任務，帶能力檢查與可續接的交接；在 Claude Code 中注入 Host Front Door、新增 tavernweave agent，並在提示行上方提供 Soul 模式開關。實際執行取決於宿主工具與許可權。

## 安裝

```
/plugin install tavernweave-agent-skills@claude-code-mods-zh
```
