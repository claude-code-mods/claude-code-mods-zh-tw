# 改寫示例


一、刪去重複限定

原文：她計劃明年開一家書店，但目前還只是打算，書店尚未開業。
改寫：她計劃明年開一家書店。

二、把動作說清楚

原文：兩人前往醫院探望老師，詢問了他的恢復情況。回校後，他們把探病所得向同學們進行了說明。
改寫：兩人去醫院探望老師，問了問他的恢復情況。回校後，他們把在醫院問到的情況告訴了同學們。

三、讓多人場景順著事情展開

原文：小周排查線路故障；小林進行裝置檢查；小陳則向觀眾解釋演出推遲的原因。三人各司其職，共同應對這一突發狀況。
改寫：小周排查線路故障，小林檢查裝置。小陳向觀眾解釋演出為什麼推遲。

四、拆開壓在名詞前面的資訊

原文：那封她在搬家時從舊書裡找到的、父親多年前寫給她卻一直沒有寄出的信，讓她重新想起了小時候的事。
改寫：搬家時，她從舊書裡找到一封信。那是父親多年前寫給她的，一直沒寄出去。這封信又讓她想起了小時候的事。

五、把補充說明接回決定

原文：他決定暫停營業，把時間用來照顧母親。母親剛做完手術，需要有人照料。只開半天店的方案被他放棄。
改寫：母親剛做完手術，需要有人照料。他放棄了只開半天店的方案，決定暫停營業，把時間留給母親。

六、說完就停

原文：她終於向朋友承認，自己一直害怕被落下。這是她第一次坦白這份恐懼，也意味著她終於願意讓朋友知道自己的不安。
改寫：她第一次向朋友坦白，自己一直害怕被落下。
