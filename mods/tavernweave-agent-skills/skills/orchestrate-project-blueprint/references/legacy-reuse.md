# 穩定作品複用協議

腦暴早期明確問：是否有使用者認可、已穩定執行或已完成驗收的舊作品、元件、互動、設計案可以參考？若有，要求提供真實路徑、倉庫、版本或執行證據。

逐項記錄：

| 決策 | 含義 |
|---|---|
| 複用 | 契約與宿主仍相容，可直接承擔新專案責任 |
| 改造 | 核心價值可保留，但介面、狀態或視覺需要遷移 |
| 僅參考 | 只借鑑結構/審美/經驗，不復制實現 |
| 拒絕 | 已知不穩定、過時、無授權或與新目標衝突 |

每項寫來源、版本、穩定證據、新責任、遷移風險和需重驗的門。不要因檔案存在、年代久、使用者喜歡或曾釋出過就判定“穩定”。第三方資產仍按原授權執行。
