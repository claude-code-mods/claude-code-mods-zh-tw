# 自治邊界與證據門

`按藍圖開跑第一版` 只授權：在當前專案工作區內，按已確認 First Playable 修改原始碼/文件，執行安全的本地靜態檢查與自動化測試，並更新權威鏈。

它不授權：

- 修改使用者級或系統級 `AGENTS.md` / `CLAUDE.md`；
- 安裝、解除安裝、重灌或改全域性環境；
- 讀取/寫入金鑰、付費 API、真實外部 POST；
- Git 提交、推送、合併、打標籤、Release；
- 部署、釋出、向第三方發訊息；
- 刪除或覆蓋歷史資料；
- 把自動化結果標成駕駛員/真機驗收。

## 證據賬本

四類證據分別報告：

1. automated：測試、驗證器、構建器；
2. static-preview：檔案、渲染、離線預覽；
3. real-host：真實客戶端、裝置、執行時；
4. driver：使用者明確驗收。

一個門透過不能替代另一門。指令碼以 `--automation` 驗證權威時，禁止把狀態寫成 `driver-accepted`。
