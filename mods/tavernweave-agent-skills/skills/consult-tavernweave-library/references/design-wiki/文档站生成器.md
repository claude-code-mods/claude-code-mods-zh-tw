# 文件站生成器

本頁**不是已採用文件棧**，也不是工坊必須換主題的工單。檢索時間：2026-08-14。賬本樞紐是 [[queries/第二批蒸餾目標]] **B2-Docs**（約 12 條），加厚見 [[10-收件箱/寫回候選/第四批-B4-Docs]]。寫法框架見 [[queries/第三批蒸餾目標]] **B3-Diataxis**；11ty / Hugo / MDX 只回 **B3-SSG**，本頁不展開。

## 一句話定義

文件站生成器是把 Markdown / MDX 等原始檔變成可瀏覽文件站點的**軟體**（主題、路由、構建）。它不管「四種文件怎麼寫」。寫法框架另走 Diátaxis / Write the Docs；**軟體 MIT ≠ 正文許可**。

## 為什麼重要

獨立文件站常被併成「裝一個開源主題」。三件事不是一層：站點怎麼建、四種文件怎麼分、正文能不能改寫再發布。生成器 MIT 只管這份軟體，不管你貼進去的手冊；Diátaxis 是 CC BY-SA，Write the Docs 帶 NC。選錯入口會把映象當樞紐，或把 Insiders 功能表整份標 MIT。

[[concepts/前端架構名詞與取捨]] 正例寫過「文件站 SSG + 搜尋島」；[[comparisons/工坊架構該上與不該上]] 把獨立站預設寫成 SSG/ISR + islands。那是架構對映，**不是**本倉庫已採用 Starlight / VitePress。

## 如何運作

### 生成器 ≠ 寫法框架

| 層 | 解決什麼 | 本頁物件 |
|---|---|---|
| 站點怎麼建 | 原始檔 → HTML、主題、路由 | Starlight / VitePress / Docusaurus / Material / Nextra / Fumadocs |
| 四種文件怎麼分 | 教程 / 操作指南 / 參考 / 解釋 | Diátaxis（`diataxis.fr`） |
| 社群寫法入門 | README、安裝、許可宣告、少用 FAQ 當正文 | Write the Docs |

用 Starlight 或 VitePress **託管**文件，不會把你複製進去的 Diátaxis 段落改成 MIT。四類目錄也不是某主題的內建功能。

### 本波核過的兩套 MIT 軟體

**Starlight** 是 Astro 上的文件主題，不是獨立語言。新建用 `npm create astro@latest -- --template starlight`；本地 `npm run dev`；新頁放 `src/content/docs/`，並點到 Pages 指南的 MDX / Markdoc。升級走 `npx @astrojs/upgrade`。LICENSE 是 MIT（Copyright 2023 Astro contributors）。

**VitePress** 官方入門寫明：Node.js **22+**；包是 ESM-only，近處 `package.json` 要 `"type": "module"`。現網安裝是 `npm add -D vitepress@next`，再 `npx vitepress init`。配置在 `.vitepress/config.js`；Markdown 在該目錄外，按檔案路由出 HTML。要改預設主題或用 Vue API，須把 `vue` 裝成依賴。LICENSE 是 MIT（Copyright 2019-present Yuxi (Evan) You）。它坐在 Vite 上，預設壓縮/轉譯見 [[concepts/構建鏈與Vite]]，本頁不重蒸。不要寫成「穩版 1.x 已釘」。

### 本波未開啟入門的三套

Docusaurus、Material for MkDocs 入門、Nextra：**本波未開啟入門頁**，不假裝讀完全文。只留 B2 樞紐與公開許可事實：Docusaurus 軟體常標 MIT，倉內 `LICENSE-docs` 是 CC BY 4.0，不要只寫「Docusaurus 是 MIT」；Material 公開主題 MIT，Insiders 是付費私倉，功能表不能整份標 MIT；Nextra 是 Next.js 文件主題。

**Fumadocs** 真源是 `fumadocs.dev`（`npm create fumadocs-app`，Node 22）。檢索會撞到 `mintlify.com/fuma-nama/fumadocs`，那是映象，不當樞紐。

### 寫法層：兩套不可混的 Creative Commons

Diátaxis `start-here` 把文件分成四類：教程（學習、在場指導）、操作指南（已勝任者的真實任務）、參考（中性事實）、解釋（背景與為什麼）。作者寫你可以只用其中一點，沒有考試。倉內 `LICENSE.rst` 與 README 都是 **CC BY-SA 4.0**。colophon：現站 Sphinx + Furo，掛 Read the Docs；引用指向 `diataxis.fr`；前身是 Divio 時期的 `documentation.divio.com`，作者說多數仍同意、若干處已改口。

Write the Docs 入門指南講 README、安裝、許可宣告、少用 FAQ 當正文。頁尾徽章與 `www` 倉 `LICENSE.md` 均為 **CC BY-NC-SA 4.0**。社群 Slack 有 `#diataxis` 頻道，這是鄰接，不是同一許可。帶 NC 的正文不能和 Diátaxis 的 BY-SA 合成一份衍生手冊。

### 許可三檔（必須分開）

| 物件 | 管什麼 | SPDX / 許可證 | 改編條件 |
|---|---|---|---|
| Starlight / VitePress 等生成器軟體 | 主題與構建**軟體** | 常見 MIT（各倉各記） | 保留版權宣告即可；不管站點正文 |
| Diátaxis | 文件**寫法**正文 | CC BY-SA 4.0 | 署名 + **ShareAlike** |
| Write the Docs | 社群指南正文 | CC BY-NC-SA 4.0 | 署名 + **NC** + SA |

Docusaurus 還要再拆一層：軟體 MIT ≠ 文件 CC BY 4.0。

### 搜尋、SSG、測試不在本頁

站內搜尋（Pagefind / DocSearch 等）見 [[concepts/站內搜尋與Pagefind]]。11ty / Hugo / MDX 見 [[queries/第三批蒸餾目標]] B3-SSG（Zola 是 EUPL-1.2，不是 MIT）。文件站截圖迴歸見 [[concepts/測試與視覺迴歸]]。本頁不升新條。

## 必須保留的衝突

- Starlight MIT ≠ VitePress MIT ≠ Diátaxis CC BY-SA。前兩份同 SPDX 也要分條，第三份不是軟體許可。
- Write the Docs **帶 NC**；Diátaxis **不帶 NC、帶 SA**。不可合成一份衍生手冊。
- Docusaurus：軟體 MIT 與文件 CC BY 4.0 是兩份檔案。不要只寫「Docusaurus 是 MIT」。
- Material for MkDocs：公開主題 MIT；Insiders 另購，功能表不能整份標 MIT。
- VitePress 官方入門現網裝的是 `vitepress@next`，並寫 Node 22+、ESM-only。不要寫成「穩版 1.x 已釘」。
- Fumadocs 真源是 `fumadocs.dev`。`mintlify.com/fuma-nama/fumadocs` 是映象，不當樞紐。
- Diátaxis 現站 ≠ Divio 舊稿。引用以 `diataxis.fr` 為準。
- 生成器解決**站點怎麼建**；Diátaxis 解決**四種文件怎麼分**。不要把四類目錄寫成某主題的內建功能。
- 11ty / Hugo / MDX 已在 B3-SSG；本頁不重收。
- 站內搜尋已在 [[concepts/站內搜尋與Pagefind]]。本頁不升新條。
- 「文件站 SSG + 搜尋島」是架構對映，**不是**本倉庫已採用某生成器。
- Docusaurus / Nextra / Material 入門本波未開啟，不把樞紐 URL 寫成「已讀完全文」。

## 例子

- 正例：用 Starlight 或 VitePress 建獨立文件站；貼進站裡的第三方手冊另核許可。
- 正例：寫法層只引 `diataxis.fr` 與 `LICENSE.rst`；不把 Write the Docs 段落並進同一份衍生手冊。
- 正例：Material 公開主題按 MIT 記；Insiders 功能單獨標付費，不寫進 MIT 表。
- 正例：Fumadocs 以 `fumadocs.dev` 為準，不引用 mintlify 映象當樞紐。
- 反例：把六套生成器 + Diátaxis + Write the Docs 併成「都是開源文件方案」。
- 反例：把教程 / 操作指南 / 參考 / 解釋寫成 Starlight 或 VitePress 的內建功能。
- 反例：把 Docusaurus / Nextra 入門寫成「本波已讀」，或把本頁寫成「工坊已採用某主題」。

## 邊界與易混概念

- 不包括：Mintlify / GitBook 報價、選題落地、成品皮膚、卡 JSON/PNG、憑證、11ty / Hugo / MDX 展開、Pagefind 逐步命令、API 風格指南（回 B3-APIsty）。
- 文件站生成器 ≠ [[concepts/概念分級]] 的 L3「滑塊 / Demo 生成器」。本頁只談文件站點軟體。
- 軟體 MIT ≠ 站點正文許可。生成器許可不覆蓋你貼上的手冊。
- VitePress ≠ Vite 整條構建鏈。預設壓縮 / 轉譯回 [[concepts/構建鏈與Vite]]。
- 搜尋島 ≠ 生成器。索引合同回 [[concepts/站內搜尋與Pagefind]]。
- 易混：聽到「開源文件方案」就以為軟體許可、寫法正文、社群指南是同一份 SPDX。
