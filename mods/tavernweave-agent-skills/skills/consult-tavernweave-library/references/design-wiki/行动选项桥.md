# 行動選項橋

模型在正文裡給選項，正則先鋪容器，橋把原文變成按鈕。點一下：預設換行填進 ST 輸入框（可多選再改），勾了直髮就立刻傳送並觸發生成。

## 卡A 4.0.0

檔案：`options_bridge.js`（卡內自包含，不依賴遠端 runtime）。

```text
正則「行動選項渲染」→ data-xyopt-root
  → 橋掃最新樓的 root
  → 解析 data-xyopt-raw
  → 往 data-xyopt-list 填 data-xyopt-choice 按鈕
  → 點選：填輸入框 或 直髮
```

舊樓被「舊樓選項隱藏」正則清空，橋不服務歷史樓。直髮/摺疊偏好在 `localStorage`。

找宿主：和其它橋一樣向上爬 `parent`，所有輸入框操作走 `hostDocument`。

Runtime key `__xyOptionsBridgeRuntime`，替換前先 destroy。

## 怪談 1.0.9

`data-kdnopt-*` 與 `data-xyopt-*` 同構。同一套直髮/摺疊/提示。開局表單是另一組 `data-kdnopen-*`，不要和選項橋混成一個根。

結算卡 `data-kdn-settlement` 是展示 MVU 分析/補丁，不是選項按鈕。

## DOM 協議

見 [[concepts/角色卡DOM與掛載點]] 的 `data-xyopt-*` 表。樣式選擇器全是屬性選擇器；根上 `container-type: inline-size`，窄了單列。

## 邊界

- 橋不寫 MVU。選項隻影響輸入框和生成觸發。
- 不要在控制中心再做一套平行選項解析。
- 卡B狀態列裡的 `data-batch-*` / 加點按鈕是 HUD 內動作，不是樓內行動選項。
