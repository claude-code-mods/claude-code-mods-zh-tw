# 中文設計系統

本頁不是已採用皮膚，也不是成品中後臺，也不是工坊必須改用四家之一的工單。檢索時間：2026-08-14。只談四家官方中文規範入口與 token / 暗色合同。賬本樞紐是 [[queries/第二批蒸餾目標]] 的 **B2-ZH**。

## 一句話定義

中文設計系統在本頁只指四家**自己用中文釋出規範**的企業級體系：Ant Design、TDesign、Arco Design、Semi Design。每家是設計語言 + token + 帶皮膚元件庫，不是「給中文排印用的系統」，也不是 Material / HIG / Fluent 的民間譯本。

## 為什麼重要

中後臺控制元件、色板、暗色和主題定製，國內產品常從這四家抄合同。先認清：誰是官方宿主、誰只是社群實現、token 怎麼派生、暗色靠演算法還是 CSS 變數。抄錯宿主或把四家併成一套「中文 Ant」，後面的皮膚和 iframe 對映都會歪。

## 如何運作

### 四家並列，不是一個「中文 Ant」

| 家族 | 誰維護 | 官方實現 | 價值觀原話 |
|---|---|---|---|
| Ant | 螞蟻集團體驗技術部 | React（`antd`） | 自然 / 確定性 / 意義感 / 生長性 |
| TDesign | 騰訊開源協同 | Vue2 / Vue3 / React 桌面與小程式等為 LTS；移動 React、Flutter、Uniapp 為 Alpha | 包容 / 多元 / 進化 / 連線 |
| Arco | 位元組 GIP UED + 基礎架構前端 | React 官方庫；Vue 是官方生態另一套 | 務實的浪漫主義 |
| Semi | 抖音前端 + MED | 只實現了 React Adapter | 優質預設（不變）+ 開放定製（多變） |

Ant [介紹](https://ant.design/docs/spec/introduce-cn) 把 [Ant Design of Vue](http://antdv.com) 標成**社群實現**。TDesign 的 Vue 是官方倉庫。不要用「Vue 也能用」把兩家實現合同併成一條。

Arco 與 Semi 都來自位元組，**不是同一套系統**。Arco 文頭寫「基於 Byte Design 升級」；Semi 從抖音 / 剪映 / 飛書等業務抽預設，再用 DSM 出品牌主題。飛書 Universe Design 是 Semi 的示例主題，不是第五家入口。

### Design Token：同名不同合同

四家都說 Design Token，派生和載體不一樣，也都不等於 [[concepts/視覺CSS與設計token]] 裡的 DTCG JSON。

- **Ant（5.0+）**：`ConfigProvider.theme`。Seed → Map → Alias 三層派生；多數情況改 Seed 即可。預設演算法：`defaultAlgorithm` / `darkAlgorithm` / `compactAlgorithm`。可巢狀區域性主題。`useToken` / `getDesignToken` 讀當前值。靜態 `message` / `Modal.xxx` / `notification` **吃不到** ConfigProvider。6.0 起 `zeroRuntime` 不再執行時生成樣式，要自己引 CSS。站點檢索日側欄見 changelog **v6.6.0**。
- **TDesign**：官方 README 寫「用 Design Token 擴充套件風格」，入口落在色彩指南。多技術棧宣稱 API 對齊；token 是跨棧皮膚開關，不是 Ant 那套 Seed 演算法。
- **Arco**：粒子變數 + Less `modifyVars`，或 [Design Lab](https://arco.design/themes)。主題頁寫明實質是 **CSS Custom properties，不相容 IE**；要 IE 得用 postcss 消掉變數。預設藍主題叫 ArcoBlue。
- **Semi**：介紹寫「數千個」變數，分層到全域性和元件。執行時明暗切換走 **CSS 變數**；不換執行時的量走 Sass。定製出口是 [DSM](https://semi.design/dsm)，可發 npm 主題包。Tokens 頁：16 色相十階；`AI general` 是 `linear-gradient()`，不能當 `background-color`。未支援全域性行高、字距、媒體查詢。預設英文字型 Inter **不打進包**。

### 暗色是四條實現，不是一個開關

Ant 設計頁把暗色定義成「整套 UI 換成深色」，原則是舒適與資訊層級不翻；色板仍是 12 套，靠透明度和生成工具出暗色階。實現上改的是 `theme.darkAlgorithm`，不是手改每一個 Alias。

TDesign 有獨立深色指南頁，和 Ant 演算法、Semi 的「任意主題自動帶深色」不是同一句話。

Semi 介紹：任意主題自動支援深色，可執行時切，可**區域性區域**開深色（SDK / 外掛）；也能跟系統主題走。暗色依賴 CSS 變數，介紹寫 IE11 及以下不行。

Arco 官方另有 [暗黑模式](https://arco.design/react/docs/dark)（倉庫 README 列出）。主題頁已宣告 CSS 變數合同；不要把 README 兼容表的 Edge 16 理解成「暗色也能在 IE 跑」。

### 拒非授權譯本

B2-ZH 只收這四家**官方中文站**。下列不進本頁、不當來源：

- Material Design、Apple HIG、Fluent、Carbon 的民間中文譯本、未授權手冊、映象站；
- 把 `antdv.com` / NG-ZORRO 寫成 Ant 設計規範真身；
- 舊 Gitee / 第三方「antd 中文手冊」若宿主不是 `ant.design`（或同文的 `ant-design.antgroup.com`）。

`ant-design.antgroup.com` 與 `ant.design` 同文雙宿主。本頁樞紐按 B2-ZH 用 `ant.design`。Element Plus、Naive UI、Vant 等未列入本批，另開賬本。B3-Gov 的 GOV.UK / USWDS 是政務體系，不是本頁。

## 必須保留的衝突

- **對映 ≠ 採用。** 本倉庫沒有因此改用 Ant / TDesign / Arco / Semi。本頁不是已採用皮膚。
- **四家不是一套。** 價值觀、色板套數、token 載體、官方框架表都不同。不要併成「中文 Ant」。
- **Arco ≠ Semi。** 同公司，兩套語言、兩套工具鏈（Design Lab vs DSM）。
- **Ant Vue 是社群，TDesign Vue 是官方。** 不要用「Vue 也能用」併成一條實現合同。
- **TDesign 穩定面不齊。** 桌面三棧與小程式、移動 Vue 為 LTS；移動 React / Flutter / Uniapp 為 Alpha。站點頁尾 `undefined` 不覆蓋 README。
- **Semi 無障礙兩套口徑。** 首頁「所有元件」；介紹承認鍵盤與焦點未全覆蓋，並指向 A11y Issue。符合性仍看 [[concepts/無障礙與包容設計]]。
- **Semi token 數量。** 介紹「數千」；營銷殼「3000+」。本頁不把營銷數寫成規範合同。
- **Token ≠ DTCG。** 四家各自的變量表不是 2025.10 CG 終稿的交換格式，見 [[concepts/視覺CSS與設計token]]。
- **Ant 4.x less ≠ 5/6 Token。** 現行主路徑是 CSS-in-JS；`zeroRuntime` 才回到靜態 CSS。
- **Arco 兼容表 vs 主題頁。** README 仍列舊瀏覽器；主題頁寫 CSS 變數不支援 IE。暗色 / 主題以主題頁為準。
- **拒非授權譯本。** 與「中文資料更好讀」不構成收進本頁的理由。

## 例子

- 正例：改 Ant 主色只動 Seed `colorPrimary`，讓演算法出 Map / Alias；不要手寫一整頁 `#1890ff` 的元件覆蓋當「官方主題」。
- 正例：TDesign 跨 Vue / React 對同一套設計指南，查的是 `tdesign.tencent.com` 與官方倉庫，不是 Ant 社群 Vue。
- 正例：Semi 暗色用顏色 token，不用寫死 hex；區域性深色給 SDK 包一層，而不是給整頁 `filter`。
- 正例：Arco 換品牌色走 Design Lab 或 `modifyVars` 的粒子變數（如 `arcoblue-6`）。
- 反例：把四家色板階數（Ant 12、Arco 13、Semi 16）併成「都是十色」。
- 反例：把飛書主題、Byte Design、Ant Design Mobile 寫成 B2-ZH 第五家。
- 反例：用民間 Material 中文手冊給卡做「中文設計系統」。
- 反例：因本頁出現 `antd` 就寫進 recipe / 髮卡依賴。

## 邊界與易混概念

- 不包括：本倉庫已採用哪套皮膚、卡 JSON/PNG、成品中後臺。
- 不包括：CLREQ / 豎排 / 注音，見 [[concepts/CJK排印與豎排]]。
- 不包括：DTCG 交換格式、Style Dictionary 流水線。
- 不包括：無頭庫（Radix / Base UI / Zag）。這些體系帶預設皮膚；無頭不管外觀，見 [[concepts/無頭元件與根節點]]。
- 不包括：原子 CSS 引擎本身，見 [[concepts/Tailwind與原子CSS]]。
- 不包括：四家之外的續名單（Element Plus / Naive / Vant 等），見 [[queries/第四批蒸餾目標]] B4-ZH。
- 易混：設計系統 ≠ 元件庫 npm 包 ≠ 設計價值觀文案。沒有 React 也能讀規範；有包不等於採用了規範。
- 易混：官方實現 vs 社群實現。Ant 的 Vue 是社群；TDesign / Arco 的 Vue 是官方生態。
- 易混：Semi 首頁營銷「所有元件鍵盤與焦點」vs 介紹頁「尚未在所有元件上完備」。符合性仍看 [[concepts/無障礙與包容設計]] 的 WCAG / APG，不看營銷句。

## 對映到本倉庫

對映，不是選型。

穩定卡和工坊今天的殼是宿主掛載、TH iframe、git-mount blob，見 [[concepts/酒館宿主與iframe分層]]。四家若只當對照：Ant 的 ConfigProvider 必須和指令碼所在 `window` 同一棵樹，靜態 Modal 還是另一棵；Semi / Arco / TDesign 的 CSS 變數跟的是**那份文件的根**，框內改不了宿主，宿主變數也進不了跨域框。Semi 介紹聲稱元件可在 Shadow DOM 工作，這仍是庫合同，不是卡側已經用 Semi。

[[concepts/前端設計庫/README-前端設計庫]] 的挑選器「加入候選」只寫本機清單，不等於採用本頁任何一家。嵌入宿主的卡 UI 仍優先 `data-*` / BEM，見 [[concepts/前端架構名詞與取捨]]。色板與增量字型合同見 [[concepts/COLRv1與增量字型]]；靜圖格式見 [[concepts/媒體格式與編解碼]]。

本頁不寫「已採用 Ant / TDesign / Arco / Semi」。
