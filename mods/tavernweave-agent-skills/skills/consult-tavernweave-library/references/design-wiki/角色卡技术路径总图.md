# 角色卡技術路徑總圖

三張已驗證穩定卡共用一條主鏈。指南庫按主題分冊（A/B/C/D/E），本頁按**執行時先後**把它們串起來，並指到 Vault 裡對應的實現頁。指南原文仍在 `<local-workspace>/<local-guide-db>/`，不搬進本 Vault。

指南庫置信度是 medium-high，手冊裡的懸案仍以手冊為準。本頁只記三張穩定卡實際走了哪條路。

## 主鏈（生成一輪）

```text
世界書掃描注入 prompt          ← A3 / [[concepts/世界書注入路徑]]
        ↓
模型輸出正文 + <UpdateVariable>  ← B1 / [[concepts/MVU變數閉環]]
        ↓
MVU bundle 打 JSONPatch
        ↓
訊息渲染：宏 → 正則 → Markdown → .mes_text
        ↓                          ← A5 A6 / [[concepts/訊息渲染與正則管線]]
顯示層掛載：OMNI / 氣泡 / 選項 / 開局殼
        ↓                          ← [[concepts/角色卡DOM與掛載點]]
HUD 讀 stat_data 重新整理
        ↓                          ← C2 / [[concepts/控制中心與狀態列]]
入口開啟：魔棒 / 懸浮球 / 抽屜 / 浮窗
                                   ← C11 C12 C13 / [[concepts/入口外殼與HUD宿主]]
```

旁路（不擋主鏈，但穩定卡都有）：

- 開局一次性向導 → [[concepts/開局頁路徑]]（C10）
- 卡A git-mount 真身 → [[concepts/git掛載與遠端真身]]（D1）
- 怪談/卡A小手機掛宿主 body → [[concepts/小手機與宿主橋]]
- 行動選項填輸入框或直髮 → [[concepts/行動選項橋]]
- 頭像立繪四源 → [[concepts/媒體庫路徑]]
- 元件回落與回封 → [[concepts/元件庫registry與recipe]]、[[concepts/打包回封路徑]]

## 三張穩定卡走法差在哪

| 路徑 | 卡A 4.0.0 | 卡B v2.6.2 | 怪談 1.0.9 |
|---|---|---|---|
| 變數 | MVU + 雙 Zod + 13 根級回落史 | 同族 MVU，宙域/機體根 | MVU + 雙 Zod，15 根回落史 |
| HUD | git-mount 真身 + 抽屜/浮窗/小手機 | 卡內 `status_bar_regex.html` | 小手機掛宿主 body |
| 開局 | 遠端開局頁，first_mes 不塞大 HTML | 控制中心，無卡A那套遠端開局 | 樓內 `data-kdnopen` 表 |
| 遠端 loader | 要 | 控制中心本地為主 | 卡內指令碼，HUD 內嵌 |
| 工坊 | 要，4.0.0 契約內嵌 | 要控制中心 | 無示例工坊 |

卡D、卡C是未出生設計檔，不進本表。
