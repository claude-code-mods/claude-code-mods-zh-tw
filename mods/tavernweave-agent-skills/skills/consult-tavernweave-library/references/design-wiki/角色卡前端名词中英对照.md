# 角色卡前端名詞中英對照

工作區口語 ↔ 程式碼標識。分三層：**酒館宿主**（ST 自己的窗和 chrome）、**TH iframe**（能跑 JS 的框）、**卡協議**（`data-*` / 殼 / 工坊）。iframe 全表和淨化鉤子在 [[concepts/酒館宿主與iframe分層]]；卡側掛載點在 [[concepts/角色卡DOM與掛載點]]。

2026-08-13 起：卡A / 卡B / 怪談是穩定髮卡名詞真源；卡C / 卡D只當設計檔名詞。實現摘錄保持原樣，不把整檔案搬進 Wiki。

## 宿主 chrome（ST 主文件）

這些在宿主頁上，不在訊息 iframe 裡。私有 DOM，不是公開 API。

| 中文 | English / identifier | 含義 |
|---|---|---|
| 宿主頁 | host document | SillyTavern 主頁面 |
| 聊天列表 | `#chat` | 樓層容器 |
| 樓層塊 | `.mes` | 一條訊息 |
| 樓號 | `[mesid]` | ST 屬性。`chats.js` 用 `.mes[mesid="${id}"]` |
| 最新樓 | `.last_mes` | 當前最後一條 |
| 正文槽 | `.mes_text` | 渲染管線終點；碎片 HTML 進這裡 |
| 推理塊 | `.mes_reasoning` | 與正文並列 |
| 主聊天殼 | `#sheld` | 寬度 `--sheldWidth`；移動端安全區 |
| 傳送區 | `#form_sheld` / `#send_form` | 底部輸入 chrome |
| 輸入框 | `#send_textarea` | 選項橋 / 小手機填這裡 |
| 傳送鈕 | `#send_but` | 宿主傳送鏈 |
| 魔棒選單 | `#extensionsMenu` / `.extensionsMenu` | 控制中心入口 |
| 頂欄 | `#top-settings` / `#navbar` / `#sheld_header` | 抽屜要避開 |
| 滑動頁 | swipe | 同一樓的備選生成 |
| 快速回復 | QR, Quick Replies | 宿主條；別在 iframe 裡重定義 `triggerSlash` |
| Custom CSS | 使用者主題 CSS | 寫宿主；引用訊息 class 要帶 `custom-` |
| movingUI | 可拖面板 | ST 內部；不當卡公開 API |
| toastr | 浮動通知 | 顯示在宿主 |

## iframe 與窗

完整分層、建立者、全域性表見 [[concepts/酒館宿主與iframe分層]]。這裡只留最常喊錯的。

| 中文 | English / identifier | 含義 |
|---|---|---|
| 指令碼框 | `TH-script--{name}--{id}` | TH 跑卡內指令碼 |
| 訊息框 / 前端介面 | `TH-message--{樓號}--{序號}` | TH 把 ` ```html ` + `<html>` 渲成 iframe |
| TH Blob 渲染 | 擴充套件設定 | TH 自己的 blob src，方便看日誌 |
| 卡內真身框 | `blob:` / `#xy-sb-inner` | 卡自己造的；預設沒有 TH 全域性 |
| 雙視窗穿透 | `hostWindow()` / `hostDocument()` | 從框裡摸宿主 |
| 變數橋 | `injectBridge` | 只給沒有 TH 的真身框補 `$` / `Mvu` |
| 認窗 | `getIframeName()` | 官方工具函式 |
| 過載框 | `reloadIframe()` | 等於 `location.reload()`，共享介面會丟 |
| 程式碼塊前端 | ` ```html ` 渲染器 | 靈感來自阡濯 html 程式碼注入器；要有 `<html></html>` |

**不是 iframe：** OMNI、氣泡、行動選項。它們是 `.mes_text` 裡的淨化 HTML。

## 淨化與樣式作用域

| 中文 | English / identifier | 含義 |
|---|---|---|
| 訊息淨化 | `MESSAGE_SANITIZE` / DOMPurify | ST 渲染最後關 |
| class 字首 | `custom-` | 每個 class token 加字首；豁免 `fa-*` / `note-*` / `monospace` |
| 樣式標籤替身 | `<custom-style>` | `<style>` 進淨化前的編碼標籤，**不是** `style=""` 改名 |
| 樓內 CSS 作用域 | `.mes_text ` 字首 | decode 時給選擇器加字首 |
| 協議屬性 | `data-*` | 淨化放行；訊息樓 JS/CSS 掛鉤 |
| 宿主主題變數 | `--sheldWidth` `--SmartThemeBodyColor` `--fontScale` | 在宿主根節點；iframe 不繼承 |

## 殼與執行時

| 中文 | English / identifier | 實現要點 |
|---|---|---|
| 控制中心 | Control Center, `control_center.js` | 卡內功能容器；TH 指令碼按鈕入口 |
| 狀態列 / HUD | Status Bar, HUD, `status_bar_regex.html` | 前臺展示與重互動 tab |
| 開局頁 | Opening page, `first_message_opening.html` | 封面啟動；first_mes 不塞大 HTML |
| 遠端掛載殼 | git-mount loader / shell | 卡內薄殼 fetch runtime 真身 |
| 真身 | payload, `status-bar.html` | 真正的 HUD HTML |
| 執行時 | runtime | `runtime/xingyue/<ver>/` 一類路徑 |
| 執行時基址 | `XY_RT_BASE`, `BASE`, `BASE_CF` | 殼用來拼 CDN/git 地址 |
| 變數橋 | `injectBridge` | blob iframe 補 `$` / `Mvu` / `getVariables` |
| 失敗即關 | fail closed | 契約無效則停用，不繞過 |
| 控制殼 | `control-shell.js` | 卡C：桌面入口 + 移動抽屜 + 宿主單例 |
| 手機橋 | `phone-bridge.js` / `kdn_bridge.js` | 白名單通訊；怪談筆記規則三寫，卡C 11 根只讀 |
| 小手機真身 | `phone-hud.html` / `kdn_phone.js` | 筆記 App 或 OS 式終端 |
| 純卡內 | card-local only | 卡C：無工坊、無開局頁、無遠端 loader |
| 最新樓只讀 | `Mvu.getMvuData({ type: 'message', message_id: 'latest' })` | 卡C P3；禁止 `replaceMvuData` |

```javascript
// 狀態列殼讀基址：優先控制中心注入，否則內聯
const base = window.XY_RT_BASE || BASE;
```

```javascript
// 卡C P3：只讀當前最新樓 11 根，不寫回
const data = Mvu.getMvuData({ type: "message", message_id: "latest" })
  || getVariables({ type: "message", message_id: "latest" });
```

隔離事實：控制中心指令碼框與狀態列訊息框不是同一 `window`，`XY_RT_BASE` 經常到不了殼，出卡必須改內聯版本段。卡A這條路與卡C的純卡內殼是兩條產品線，不要混裝遠端 loader。

```javascript
// media_library.js 概念：掃掛載點再拉 runtime 模板
document.querySelectorAll("[data-xy-omni]").forEach((el) => {
  const type = el.getAttribute("data-xy-omni"); // analysis | done | progress
  // fetch(`${XY_RT_BASE}/omni-${type}.html`) → {{CONTENT}} → wireOmniButtons

```

```javascript
// 不跨同名標籤（analysis_omni）
const findRegex = /<analysis>\s*((?:(?!<\/?analysis>)[\s\S])*?)\s*<\/analysis>/gi;
```

SillyTavern 會給訊息 class 加 `custom-` 字首，所以：

```css
/* 會失配 */
.omni-analysis summary::marker { display: none; }
/* 要用 */
[data-xy-omni="analysis"] summary::-webkit-details-marker { display: none; }
```

## 邊界

- 宿主選擇器（`#send_textarea`、`#extensionsMenu`）是 ST 私有 DOM，不是穩定公開 API；新程式碼優先 TH 命令。官方 iframe 名以酒館助手文件為準，見 [[concepts/酒館宿主與iframe分層]]。
- 未把 Zod 裡的私密身體欄位展開進本頁；那是變數 schema，不是前端殼名詞。
- 卡D多數前端仍是沙盤，識別符號以設計稿與卡A/怪談筆記已有實現為準。
