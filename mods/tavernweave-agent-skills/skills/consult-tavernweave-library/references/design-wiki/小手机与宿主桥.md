# 小手機與宿主橋

小手機不是訊息樓裡的一塊正則 HTML。它是掛在 **SillyTavern 宿主 `document.body`** 上的單例抽屜，自己讀 MVU、自己跟輸入框說話。怪談 1.0.9 是這條路的真源；卡A 4.0.0 從怪談 1.0.8 骨架移植並改名。

## 職責（`kdn_bridge.js` 檔案頭）

1. HUD HTML 內嵌在腳本里，不讀角色卡 `extensions.*.hud_html`。
2. 抽屜單例掛宿主 body，不依賴訊息樓，也不等 `<UpdateVariable>` 才出現。
3. 提供 MVU 快照、事件委託、傳送/填入橋；變數或訊息變了就重新整理。

卡A對應物：`phone-bridge` 懶載入進控制中心，根節點 `#xy-phone-root` / `data-xyph-hud-root`。橋名 `__xyPhoneSend`、`__xyPhoneInput`、`__xyPhoneStat` 等。

## 宿主怎麼找

```text
當前 window
  → 最多向上 parent 4 層
  → 能摸到 parent.document.body 就繼續
  → 得到 hostWindow / hostDocument
```

熱過載先 `previous.destroy('replace')`，再掛新 runtime。key：怪談 `__kdnHudRuntime` / `__kdnBridgeRuntime`；卡A `__xyPhoneBridgeRuntime`。

## 和訊息樓 HUD 的差別

| | 小手機 | 正則狀態列 |
|---|---|---|
| 掛哪 | 宿主 body | 訊息 iframe / blob |
| 幾份 | 單例 | 每樓可能一份，要去重 |
| 變數 | 提交去抖後的快照 | 當前樓 `getVariables` / `Mvu.getMvuData` |
| 皮膚 | `data-kdn-shell` / `data-kdn-charm` | 卡內 CSS |

移動端抽屜外殼（安全區、軟鍵盤、`visualViewport`）見 C12 和 [[concepts/入口外殼與HUD宿主]]。小手機可以是抽屜裡的內容，也可以自己就是那隻抽屜。

## 怪談多寫一口

寫下規則時三寫：MVU 變數、世界書動態條目、玩家行動訊息。橋是白名單，不是把整個 `stat_data` 暴露給 HUD 亂寫。

## 邊界

- 不要把小手機再塞進 `first_mes`。
- 不要和 git-mount 狀態列搶同一套 `injectBridge` 假設：小手機在宿主頁，TH 全域性通常在。
- 卡C設計檔的 `control-shell.js` / 11 根只讀是未出生方案，名詞可對照，不當穩定髮卡。
