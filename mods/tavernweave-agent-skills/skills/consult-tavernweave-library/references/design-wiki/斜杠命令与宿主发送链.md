# 斜槓命令與宿主傳送鏈

穩定卡從 iframe / 小手機把字送到酒館，不靠直接改輸入框再點發送。走酒館助手 `triggerSlash`。指南 B2 是 STScript 總冊；本頁只記三張穩定卡實際用的幾條。B2 全套命令**未走**。

## 穩定卡用到的

| 命令 | 誰調 | 幹什麼 |
|---|---|---|
| `/setinput <文字>` | `options_bridge.js`、`kdn_bridge.js` | 把選項或開局設定填進 `#send_textarea`。換行寫成 `{{newline}}` |
| `/send <文字>` | 同上，直髮模式 | 追加一條玩家訊息 |
| `/trigger` | 跟在 `/send` 後面用管道 | 觸發生成。`/send` 單獨**不會**開生成 |

直髮實現（卡A 4.0.0 / 怪談同構）：

```text
/send <選項> | /trigger
```

管道里的 `|` 若出現在使用者文本里要先轉義。

找命令介面：`TavernHelper.triggerSlash`，或注入的自由函式 `triggerSlash`。沒有就 fail，不要退化成 `input.value = …; send_but.click()` 當正式路徑。

讀當前輸入仍可 `hostDocument.querySelector('#send_textarea')`，那是私有 DOM，只用來拼接「已有草稿 + 新選項」。

## 和 QR 的坑

TH 文件：不要在前端程式碼裡自己定義 `triggerSlash`，會蓋掉擴充套件的函式，QR 失效。卡側橋只調用，不宣告同名函式。

## 事件：什麼時候重掃樓

| 事件 | 誰聽 | 幹什麼 |
|---|---|---|
| `tavern_events.CHAT_CHANGED` | 選項橋、媒體庫、控制中心 | 切聊天后重掃 / 延時重掛魔棒 |
| `MESSAGE_UPDATED` / `GENERATION_ENDED` | 選項橋 | 新樓選項出現後渲染 |
| `USER_MESSAGE_RENDERED` / `CHARACTER_MESSAGE_RENDERED` / `MESSAGE_SWIPED` | 媒體庫 | 氣泡、OMNI 掛載 |

控制中心生產模式：`CHAT_CHANGED` 後 **250ms** 再 `ensureWandEntry()`，等 ST 重建頂欄。不要假定按鈕還在。

## 邊界

- 本頁不是 B2 命令大全。`/gen` `/inject` `/let` 等穩定卡主路徑不用。
- 開局提交：怪談用 `/setinput` 填「【開局設定】…」讓玩家自己發；卡A遠端開局另有世界書事務 + 真實玩家訊息，見 [[concepts/開局頁路徑]]。
