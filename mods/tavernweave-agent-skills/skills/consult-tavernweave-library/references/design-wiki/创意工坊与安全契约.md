# 創意工坊與安全契約

工坊是卡A（以及計劃中的卡D）的內容管線，不是 HUD。指南：`E5_創意工坊與擴充套件生態.md`。怪談、卡C設計檔**不裝**工坊。

## 四層不要叫成「外掛」

| 層 | 載體 | 本卡怎麼用 |
|---|---|---|
| ST UI Extension | 宿主擴充套件 | 不管 |
| ST Server Plugin | Node | 不管 |
| TH 卡內指令碼 | ScriptTree / srcdoc | 控制中心、Zod、媒體庫 |
| 創意工坊 | 卡內客戶端 + Gateway + 儲存 | 只寫受控世界書條目 |

工坊包**不是**任意指令碼、prompt patch 或 MVU patch。匯入只碰聊天世界書，例如 `[世界因子]當前設定`、`[創意工坊][型別]標題`。

## ScriptTree 與魔棒

當前 TH 用 `ScriptTree[]`（或卡內 `tavern_helper.scripts` 樹），不是舊 `scripts` 物件。

`getButtonEvent(buttonName)` 匹配 **`button.buttons[].name`**，不是指令碼 `name`。卡B控制中心按鈕名是 `卡B控制中心`。卡A控制中心 ScriptTree 上沒有按鈕，入口另掛 `#extensionsMenu`（私有 DOM，`CHAT_CHANGED` 後要重掛）。

## 卡A 4.0.0 契約時序

雲酒館曾出現：控制中心已啟動，安全契約 `1.1.0` 未就緒，工坊 runtime 搶跑。4.0.0 把契約內嵌進控制中心：

```text
啟動 CC
  → 校驗內嵌契約 1.1.0（遠端仍首選）
  → 雙失敗 → fail closed，不載入工坊 runtime
  → 成功 → 再開工坊 iframe
```

Bridge 只暴露有限 action（handshake / getEntries / upsertWorkshopEntries …），要 origin allowlist，禁止 `postMessage('*')`。

## 邊界

- 卡D長期內容管線在設計檔裡，沒有穩定髮卡工坊。
- Gateway token、OAuth、Cloudreve 不進本 Vault。
- 詳細 schema 以工作區 `rolecard-diy-workshop/schemas/` 為準，本頁不復制。
