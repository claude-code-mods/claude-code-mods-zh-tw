# 動畫庫與動效管線

動效先分兩層：瀏覽器自己會的（CSS / Web Animations / View Transitions / 滾動驅動），和庫在上面補的（時間軸、彈簧、手勢、向量執行時）。本頁是行業蒸餾，不按「角色卡能不能用」刪名詞。許可以各站原文為準，落地前再核一次。靈感入口賬本見 [[queries/前端視覺與靈感站點蒸餾目標]]。視覺層疊與玻璃見 [[concepts/視覺CSS與設計token]]。

B2-Anim-15 / B2-VT / B2-Scroll-12 與第一批 WAAPI、View Transitions、scroll-driven 是同文重疊，不是新 API。本頁只補預設緩動、同文檔/跨文件基線和第二波庫。

## 一句話定義

動效管線決定「誰在改哪些屬性、按什麼曲線、能不能打斷、使用者能不能關掉」。庫是這條管線上的加速器，不是替代瀏覽器合同。

## 為什麼重要

同一套「按鈕彈一下 / 抽屜滑上來 / 頁面轉場 / 機甲準星呼吸」可以只寫 CSS，也可以上時間軸庫或向量執行時。選錯的代價是包體積、許可、主執行緒卡頓，以及忽略 `prefers-reduced-motion`。

## 平臺層（先認瀏覽器）

| 名詞 | 管什麼 | 優點 | 缺點 | 來源 |
|---|---|---|---|---|
| CSS Transitions | 屬性從 A 變到 B | 零依賴、合成層友好 | 編排弱；打斷和交錯要自己寫 | [MDN transitions](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_transitions) |
| CSS Animations | `@keyframes` 多段 | 宣告式、可迴圈 | 和 JS 狀態同步笨；不能輕易彈簧 | [MDN animations](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_animations) |
| Web Animations API | JS 控制同一套動畫引擎 | 可暫停/反轉/時間線；Motion 也走這條 | 要寫 JS；舊環境要墊 | [MDN WAAPI](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API) |
| View Transitions | 兩態之間的快照轉場 | 原生跨 DOM 更新的過渡 | **同文檔**已是 Baseline Newly（Firefox 144）；**跨文件**仍 Limited | [MDN View Transition](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API)；[web.dev 同文檔 Baseline](https://web.dev/blog/same-document-view-transitions-are-now-baseline-newly-available) |
| Scroll-driven | 動畫進度綁滾動 | 少寫 IntersectionObserver | 新特性；相容要查 Can I use | [MDN scroll-driven](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations) |
| `prefers-reduced-motion` | 使用者要少動 | 合規底線 | 只宣告偏好，庫不會自動替你關完 | [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)；[WCAG](https://www.w3.org/WAI/standards-guidelines/wcag/) |

緩動本身不是庫。[easings.net](https://easings.net/) 給常見曲線的公式和視覺化；[cubic-bezier.com](https://cubic-bezier.com/) 調 `cubic-bezier()`。CSS `easing-function` 能表達的，不必為一條曲線引入 JS。

[CSS Easing 2](https://www.w3.org/TR/css-easing-2/) **沒有**原生 `spring()`。bounce / spring 要用 [`linear()`](https://developer.chrome.com/docs/css-ui/css-linear-easing-function) 多點折線逼近，這是預計算曲線，不是執行時彈簧。真彈簧仍走 JS（Motion / GSAP）。

同一引擎預設緩動不同：CSS `animation` 預設 `ease`；WAAPI `element.animate()` 預設 `linear`。CSS 的 timing-function 作用在每一對 keyframe 之間；WAAPI options 上的 `easing` 作用在整段 effect。

## JS / 框架庫

| 庫 | 何時用 | 優點 | 缺點 / 許可 | 來源 |
|---|---|---|---|---|
| [GSAP](https://gsap.com/) | 跨框架時間軸、滾動、字元/路徑、要精確編排 | 時間軸強；外掛面大；Demo Hub 可點 | 包比一段 CSS 重。2025-04-30 起 Standard No Charge：網站/應用商用免費；**禁止**做成和 Webflow 搶生意的「無程式碼視覺化動畫構建器」 | [Standard License](https://gsap.com/community/standard-license/)；[Webflow 公告](https://webflow.com/blog/gsap-becomes-free)；[Eases](https://gsap.com/docs/v3/Eases/)；[Demo Hub](https://demos.gsap.com/) |
| [Motion](https://motion.dev/)（原 Framer Motion） | React / JS / Vue 裡宣告式 UI 動效、手勢、佈局動畫 | 簡單情況走 WAAPI/ScrollTimeline；彈簧、打斷、手勢再回 JS。核心 MIT | 和 React 最貼；純 HTML 要改寫。Motion+ 是一次性付費的示例/高階 API/AI Kit，不是核心庫門票 | [React 入門](https://motion.dev/docs/react-quick-start)；[Examples](https://motion.dev/examples)；[Motion+](https://motion.dev/plus) |
| [Anime.js](https://animejs.com/) | 要輕量 JS 時間軸、不綁 React | API 面小、好上手 | 生態和外掛不如 GSAP 深 | 官網 |
| [Lottie](https://airbnb.github.io/lottie/#/) | 設計師從 After Effects 出 JSON，執行時播向量 | 設計/開發交接清楚 | 執行時 + JSON 體積；複雜 AE 特性會丟；要獨立播放器 | Airbnb Lottie 文件 |
| [Rive](https://rive.app/) | 狀態機驅動的互動向量（按鈕、角色、HUD 儀表） | 編輯器裡編狀態，執行時聽輸入 | 執行時 MIT；**匯出上生產要付費**（2025-10-20 起 Cadet 起才無限匯出） | [rive.app](https://rive.app/)；[匯出說明](https://rive.app/docs/editor/exporting/exporting-for-runtime) |

### 第二波庫（Theatre / 滾動 / 3D 執行時）

全部 candidate，不是已採用。

| 庫 | 何時看 | 許可 / 坑 | 來源 |
|---|---|---|---|
| [Theatre.js](https://www.theatrejs.com/docs/latest) | 瀏覽器裡用時間軸編 3D/UI | `@theatre/core` Apache-2.0；`@theatre/studio` AGPL-3.0，生產包不應打進 studio | [GitHub](https://github.com/theatre-js/theatre) |
| [Lenis](https://github.com/darkroomengineering/lenis) | 平滑滾動且儘量走原生捲軸 | MIT | 倉 |
| [Locomotive Scroll v5](https://scroll.locomotive.ca/docs/) | 在 Lenis 上加視口檢測 / 視差 | v5 引擎是 Lenis；不要把 v4 當現行合同 | 官方 docs |
| Spline runtime | 嵌入 Spline 場景 | **無 SPDX**；`@splinetool/react-spline` 是 MIT，runtime 沒有 LICENSE | npm / [issue 234](https://github.com/splinetool/react-spline/issues/234) |
| [Unicorn Studio](https://www.unicorn.studio/docs/pricing/) | 無程式碼 WebGL 場景 | 執行時專有；匯出上生產要付費 | 定價頁 |

GSAP 舊口徑「Club 外掛要付費 / 商用另買」以 2025-04-30 為準作廢。本頁按 Standard License 與 Webflow 公告寫。禁止用途只覆蓋「無程式碼視覺化動畫構建器」這類競爭產品，不覆蓋普通網站或應用裡的動效。

Motion 自己寫：簡單 hover/顏色用 CSS 更輕；要和 React state、手勢、layout 繫結再上庫。核心開源 MIT；付費的是 Motion+ 的示例原始碼和高階件，買完按他們的條款用於專案，不能把 Plus 原始碼再打包成競品庫。

## 生成器與過時件

| 入口 | 角色 | 注意 |
|---|---|---|
| [Animista](https://animista.net/) | 調 `@keyframes`，帶走用到的那幾條 | 不要把整站生成物當設計系統 |
| [Hover.css](https://ianlunn.github.io/Hover/) | 2010 年代 hover 類名集 | 過時；新活優先 CSS transition 或平臺 API |
| GSAP Demo Hub / Motion Examples | 看手感、抄編排思路 | Demo ≠ 已採用皮膚；Motion 部分示例在 Plus 牆後 |

## 怎麼選（行業，不是卡規）

```text
只要屬性 A→B、可宣告
  → CSS transition / animation
要 JS 控制同一條動畫（暫停、進度、編排）且不想上庫
  → Web Animations API
跨文件/跨樹的頁面轉場
  → View Transitions（不夠再補庫）
進度必須跟滾動走
  → CSS scroll-driven；不夠再 GSAP ScrollTrigger / Motion useScroll
React 裡手勢 + layout + 進出場
  → Motion
跨框架、長時間軸、路徑/字元
  → GSAP
設計師交 AE / 狀態機向量
  → Lottie 或 Rive
```

無論哪條：先接 `prefers-reduced-motion`。大位移、迴圈閃爍、自動播放要可關。WCAG 不因用了某庫而豁免。

## 例子

- 正例：按鈕 hover 用 CSS transition；列表進出用 WAAPI 或 Motion；長滾動敘事用 GSAP 時間軸。
- 正例：核過 GSAP Standard License 後，商用站點直接用含原 Club 外掛的標準包。
- 反例：為一條 `opacity` 漸變引入 GSAP + ScrollTrigger。
- 反例：把 Motion+ 示例原始碼再發行成自己的元件庫去賣。
- 反例：忽略 `prefers-reduced-motion`，讓準星和掃描線一直閃。

## 邊界與易混概念

- 本頁不是「本倉庫已採用 GSAP/Motion」的宣告。
- CSS 動畫和 WAAPI 是同一引擎的兩種入口，不是兩套互斥世界觀。
- GSAP「已免費」≠ 無條款；競爭 Webflow 的視覺化構建器仍禁止。
- Motion 核心免費 ≠ Motion+ 示例免費。
- Lottie 不是通用 JS 動畫庫，是播放預烘焙向量。
- CSS 無原生 `spring()`；`linear()` 取樣 ≠ 執行時彈簧。
- View Transitions：同文檔 Baseline Newly，跨文件 Limited。不要寫「已經 Baseline」而不加「同文檔」。
- Theatre studio 是 AGPL；Spline runtime 無 SPDX；Unicorn / Rive 匯出上生產要付費。
- iframe 裡的動畫仍相對該框的文件和視口；`1vh`、跨文件 `backdrop-filter` 見 [[concepts/視覺CSS與設計token]]、[[comparisons/嵌入三路徑對照]]。

## 對映到本倉庫

角色卡 HUD 能用平臺 CSS / WAAPI，也能嵌 GSAP 或 Motion——本頁不因為「卡」就刪庫。約束是包體積、許可、以及動效不要穿透宿主訊息樓的淨化規則。工坊站和獨立站點按上面的「怎麼選」。產品級「工坊該不該上 SPA」見 [[comparisons/工坊架構該上與不該上]]，不要和本頁的庫清單混成一句「所以都不要」。
