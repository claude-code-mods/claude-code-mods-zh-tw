# 測試與視覺迴歸

本頁不是已採用測試棧，也不是工坊 CI 配方。檢索時間：2026-08-15（入口直讀日 2026-08-14）。賬本樞紐是 [[queries/第二批蒸餾目標]] **B2-Test**；12 條入口、舊文件 404 與三條合同見 [[10-收件箱/寫回候選/第四批-B4-VRT]]。只談公開文件，不寫攻擊、憑證或 Percy 教程。

## 一句話定義

測試與視覺迴歸不是一種工具。Playwright 是跑用例的 **runner**；畫素對照、ARIA 樹快照、axe 掃描、Testing Library 查詢、MSW 網路樁、Chromatic 雲迴歸是**不同合同**。聽到「做了 VRT」先問：比的是畫素、無障礙樹，還是雲端檔案。

## 為什麼重要

HUD、文件站、動效和 iframe 都會讓「看起來沒壞」說謊。畫素金圖會因作業系統、瀏覽器版本、電源和動畫抖動；ARIA 快照抓不到色偏；axe 過了仍可能不符合 WCAG。混用舊 URL 或把 Chromatic 寫成 MIT，會裝錯包、鏈到 404。本頁只分層，不選棧。前端取捨見 [[concepts/前端架構名詞與取捨]]，不在這裡重開架構頁。

## 如何運作

七層不要併成「一種測試」。

### Playwright runner

[Intro](https://playwright.dev/docs/intro) 管安裝、專案腳手架和用例怎麼跑。截圖斷言**只**在 Playwright test runner 裡工作。它提供 `getByRole` 等定位器，但 **Playwright 不是 Testing Library**，也不是元件測試庫。本頁不寫本倉庫 CI 配方。

### 畫素對照：`toHaveScreenshot`

[Visual comparisons](https://playwright.dev/docs/test-snapshots) 寫明：`expect(page).toHaveScreenshot()` 會等到**連續兩張**截圖一致，再跟金圖比。比較庫是 pixelmatch。可調 `maxDiffPixels` / `stylePath`（用 CSS 藏動態塊）。預設 PNG；檔名用 `.webp` 則存無損 WebP。金圖目錄是 `*.spec.ts-snapshots`，檔名帶瀏覽器與平臺（如 `chromium-darwin`）。官方警告：渲染隨 OS、版本、硬體、電源、headless 變；基線必須在**同一環境**生成。首次跑會寫金圖；更新：`npx playwright test --update-snapshots`。

`toMatchSnapshot()` 仍在，但現行視覺頁把它留給文字/二進位制，不是畫素主路徑。舊文/部落格常見 `expect(screenshot).toMatchSnapshot('x.png')`——那是另一條合同。

動效會抖基線。大位移、迴圈動畫、未凍結的時間軸會讓連續兩幀對不齊，或讓金圖在 CI 裡閃紅。對映 [[concepts/動畫庫與動效管線]] 的 `prefers-reduced-motion` 與可關動效，不是新發現，也不在本頁重寫緩動。

### ARIA 快照

[Aria snapshots](https://playwright.dev/docs/aria-snapshots) 比的是 YAML 角色樹（role / name / 狀態），不是畫素。預設跨瀏覽器只存一份 `.aria.yml`。這能抓住「按鈕沒了 / 標題級錯了」，抓不住「差 2px / 色偏」。不要和上一節併成「一種 snapshot」。

### axe-core

Playwright 無障礙頁官方接 `@axe-core/playwright` 的 `AxeBuilder`。[axe API](https://www.deque.com/axe/core-documentation/api-documentation/)：本地跑、不連第三方伺服器；能進巢狀 iframe；**隱藏區不測**。`AxeBuilder.analyze()` 只看呼叫瞬間的已渲染樹；隱藏選單/模態要先開啟再掃。`exclude()` 會排除子孫且關掉該節點上**全部**規則。`setLegacyMode()` 官方標最後手段，會關掉跨源 frame 測試。

官方示例 `withTags(['wcag2a','wcag2aa','wcag21a','wcag21aa'])`，**沒有** `wcag22*`。axe 標籤表有 `wcag22aa`，**沒有** `wcag22a`。`best-practice` 與 `experimental` 不是符合性標籤。

Playwright 無障礙頁自己寫：自動掃描只能抓一部分；許多問題只能手測。它推薦 [Accessibility Insights for Web](https://accessibilityinsights.io/docs/web/getstarted/fastpass/?referrer=playwright-accessibility-testing-js) 做 **WCAG 2.1 AA** 人工走查——注意是 2.1，不是本庫已蒸的 WCAG 2.2 Rec。

**axe 過 ≠ WCAG 符合**；跟 APG ≠ Rec。規範分層見 [[concepts/無障礙與包容設計]]，本頁不重抄那一頁。

### Testing Library 查詢優先順序

[About Queries](https://testing-library.com/docs/queries/about/) 不是 runner。官方優先序：`getByRole` → label → placeholder → text → displayValue → alt → title → `getByTestId`（最不優先）。賬本 B4-VRT-06 收成主鏈 `getByRole` → label → placeholder → text → testid。

Testing Library 的 `getByRole` 與 Playwright 的 `getByRole` 同族優先順序，但 TL 不是 E2E runner，PW 不是元件庫。不要把一份查詢示例改兩個庫名交差。

### MSW v2

[Quick start](https://mswjs.io/docs/quick-start) 現行是 `http` + `HttpResponse`。Node 用 `setupServer`，瀏覽器用 `setupWorker`。MSW v1 的 `rest` / `graphql` 命名已不是 quick start。本頁只記樁合同，不寫攔截繞過或憑證。

### Chromatic 雲迴歸

Chromatic 是**商業雲工具鏈，不是 MIT 庫**。樞紐：[docs](https://www.chromatic.com/docs/)（`docs.chromatic.com` 同殼）。

Playwright 線：把 `@playwright/test` 換成 `@chromatic-com/playwright` 的 `test` / `expect`，再 `npx chromatic --playwright`。Storybook 線：現包 `@chromatic-com/storybook`；舊 `@chromaui/addon-visual-tests` **已棄**，舊 npm 頁仍在，不當新裝入口。`chromatic.viewports` 目錄標 **legacy**，改走 Modes。

營銷頁寫它存 DOM + 樣式 + 資源檔案，不只一張 PNG。Flake filter / 暫停動畫是雲側穩定手段，對不上 Playwright 本機 `stylePath`。Playwright 視覺頁要「同一環境」；Chromatic 賣點是雲端統一瀏覽器。不要寫成同一條 VRT。

Storybook 官方視覺測頁把跨瀏覽器視覺測指到 Chromatic。文件站怎麼生成見 [[concepts/文件站生成器]]，本頁不重開生成器。

## 必須保留的衝突

- 舊文用 `expect(screenshot).toMatchSnapshot('x.png')`；現行視覺頁主推 `toHaveScreenshot()`。兩條都還在，合同不同。
- Playwright 視覺頁要「同一環境」；Chromatic 賣點是雲端統一瀏覽器。不要寫成同一條 VRT。
- `toHaveScreenshot` 是畫素；`toMatchAriaSnapshot` 是 YAML 樹。不是一種 snapshot。
- Playwright 無障礙示例釘 WCAG 2.0/2.1 標籤；本庫無障礙頁釘 2.2 Rec。兩邊都留。
- Testing Library `getByRole` 與 Playwright `getByRole` 同族，但 TL ≠ E2E runner，PW ≠ 元件庫。
- MSW v1 的 `rest` / `graphql` 已不是 quick start；現網是 `http` / `HttpResponse`。
- `@chromaui/addon-visual-tests` 已改名 `@chromatic-com/storybook`。舊包不當新裝入口。
- Chromatic `/docs/visual-testing` 與 `/docs/visual-tests` **硬 404**；不要從舊教程抄這兩條。
- Chromatic **不是 MIT**。
- iframe / Shadow DOM：axe 測巢狀 iframe，跨源要看 legacy；Chromatic 另有 Shadow DOM 互動測。對映 [[concepts/酒館宿主與iframe分層]]，不是已採用。
- 本頁對映行業測試分層；**不是**「本倉庫已採用 Playwright / axe / Chromatic」。

## 例子

- 正例：畫素迴歸走 `/docs/test-snapshots` 的 `toHaveScreenshot()`；金圖在同一 CI 映象裡生成。
- 正例：要鎖「這個按鈕還在、名字沒丟」用 ARIA 快照，不拿它當色偏檢測。
- 正例：axe 只當自動掃描層；符合性仍手測，並回到 [[concepts/無障礙與包容設計]] 的 WCAG 2.2 Rec。
- 正例：元件查詢按 Testing Library 優先序；網路樁用 MSW v2 的 `http` / `HttpResponse`。
- 反例：把 `toMatchAriaSnapshot` 寫成畫素 VRT，或把 Chromatic 寫成 MIT。
- 反例：從舊教程抄 `/docs/visual-testing`、`/docs/test-screenshots`，或新裝 `@chromaui/addon-visual-tests`。
- 反例：axe 綠了就寫「已符合 WCAG」；或示例只開 `wcag21aa` 卻聲稱覆蓋 2.2。
- 反例：未凍結動畫就鎖畫素金圖，再把閃紅當成「CI 壞了」。

## 邊界與易混概念

- 不包括：本倉庫 CI yaml、卡 JSON/PNG、成品皮膚、憑證、攻擊或繞過、Percy / Lost Pixel / 付費課。
- 不包括：k6 / Pact（B3-Load）、Storybook 生成器全文（B3-SB；本頁只收 Chromatic 合同）。
- runner ≠ 畫素斷言 ≠ ARIA 快照 ≠ axe 掃描 ≠ 查詢庫 ≠ 網路樁 ≠ 雲迴歸。
- `page.screenshot()` ≠ `toHaveScreenshot()`。前者取畫素，後者是 runner 內的金圖斷言。
- axe 過 ≠ WCAG 符合；APG ≠ Rec。不在本頁重寫規範層。
- Chromatic 雲檔案 ≠ Playwright 本機 PNG 金圖。
- 易混：聽到「snapshot」就以為一定是畫素。先問檔案是 `.png` / `.webp` 還是 `.aria.yml`。

## 對映到本倉庫

當前工坊沒有已採用的 Playwright / axe / MSW / Chromatic 棧。本頁只問：若要測，先分清比的是哪一層，不要把七種合同寫成一種「上了測試」。

對齊方式是**按層選合同**：本地畫素走 `toHaveScreenshot`；鎖語義走 ARIA 快照；自動掃描走 axe 並承認缺口；元件查詢走 Testing Library 優先序；網路樁走 MSW v2；跨瀏覽器雲迴歸若選 Chromatic，按現行包名與 `/docs/`，不要抄 404 舊徑。這是「測試分層要穩定」，不是「工坊必須上 Chromatic」。

角色卡只在這裡點名、不當過濾器：HUD / 懸浮層動效會抖畫素基線，先看 [[concepts/動畫庫與動效管線]]；跨文件 iframe 與 Shadow 的掃描範圍見 [[concepts/酒館宿主與iframe分層]]；文件站若做視覺測，生成器歸 [[concepts/文件站生成器]]，本頁只標 Storybook 官方把跨瀏覽器視覺測指到 Chromatic。前端怎麼切頁面見 [[concepts/前端架構名詞與取捨]]。本 Vault 不收測試賬號或雲服務令牌。
