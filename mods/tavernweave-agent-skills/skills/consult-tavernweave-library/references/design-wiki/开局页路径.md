# 開局頁路徑

自定義開局是**一次性初始化器**：玩家填完，發出一條真實玩家開局訊息，然後回到正常多樓層。若首樓此後還代理每一輪輸入和生成，那就滑進 C5 同層前端。三張穩定卡都不走 C5。指南：`C10_開局頁與自定義開局.md`。

## 三類開局

| 型別 | 生命週期 | 穩定卡 |
|---|---|---|
| 普通 `first_mes` | 展示一條首訊息 | 卡A 4.0.0 的 `first_message_opening.html` 只留標記行 |
| `alternate_greetings` | 首訊息候選 | 可用，但不是卡A主嚮導 |
| 自定義開局頁 | 嚮導 → 提交真實玩家訊息 → 退出 | 卡A遠端開局；怪談樓內授予者表 |

## 卡A 4.0.0

```text
first_mes 標記
  → 正則 opening_expand 在樓裡放 data-xy-opening-remote
  → 控制中心按 phase/remote-state 拉 runtime 開局真身
  → 草稿 OpeningDraftV2（按聊天 metadata UUID 分割槽）
  → 預覽 / 校驗
  → 提交：世界書管理器寫身份，再發真實玩家開局發言
  → 開局頁卸掉，後面是普通樓
```

`data-xy-remote-state`：`idle` / `loading` / `loaded` / `error`。失敗可 `data-xy-opening-retry`。契約未就緒則 fail closed，見 4.0.0 工坊競態修復。

死守：`first_mes` 不塞大 HTML，否則上下文爆炸（C2 避坑 7.5）。剝離用 `opening_prompt_strip_regex.html`。

開局嚮導可以複用控制中心的世界書/媒體能力，但不能讓控制中心變成第二套提交真值。C10：一個草稿模型，一個提交事務。

## 怪談 1.0.9

沒有卡A那套遠端開局頁。樓內 `data-kdnopen-root` 表單，`data-kdnopen="欄位名"` 收集授予者態度等，`data-kdnopen-go` / `-skip` 寫入輸入框後由玩家傳送。地理進 `環境`。橋在 `kdn_bridge.js`。

## 卡B v2.6.2

同族控制中心入口。不把卡A遠端開局當本卡必裝件。`first_mes` 是玩家手冊；起源十選一寫在**一條** `alternate_greetings` 裡（不是十條問候）。標題見創意庫世界觀頁。C.Z.03 / C.Z.20 紀年衝突未裁。

## 邊界

- 開局頁 script 在訊息樓裡不一定執行（C2 7.8）。卡A把邏輯放控制中心 / runtime，不靠樓內裸 `<script>`。
- 卡C設計檔去掉開局頁，不在本路徑。
