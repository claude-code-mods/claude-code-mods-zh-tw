# 概念分級

本庫的概念頁按**職責分層**，不按「能不能用在角色卡上」刪名詞。行業正文仍在根目錄 `concepts/*.md`；挑選用的目錄和 HTML 另放，避免搬頁斷鏈。

## 五級

| 級 | 名字 | 放什麼 | 不當成什麼 |
|---|---|---|---|
| L0 | 規範 | W3C / MDN / RFC 合同 | 本倉庫皮膚 |
| L1 | 概念 | 已蒸正式頁：定義、衝突、對映 | 成品實現 |
| L2 | 庫 | 可開啟原始碼或文件的實現 | 已採用棧 |
| L3 | 生成器 | 滑塊、配方、Demo | 設計系統 |
| L4 | 靈感 | 畫廊、市場、截圖站 | 許可已核 / 可商用 |

L0–L1 先認合同。L2–L4 用來挑手感和入口，挑中的項要再核許可與相容，不能從挑選器直接升格成「本倉庫已採用」。

設計 / 動效側欄：點一條就出沙盤；沒有沙盤、能嵌的出源站。不要預設要點片。賬本能實裝的分路掛沙盤；Kafka / Helm / 規範長文等仍只出要點。規範、HIG、GitHub、價目、長文、基建合同仍不嵌，也不造假沙盤。

243 路分路已標主題並掛最近的正式概念頁（沒有專頁的不硬造）。設計 / 動效仍只收能當樣本的條，不是把八批入口全搬進側欄。

賬本行仍以 [[queries/前端視覺與靈感站點蒸餾目標]] 至 [[queries/第八批蒸餾目標]] 和收件箱分路原稿為真源。挑選頁只做篩選面，不替代查詢頁，也不把賬本升成已採用。
