# 媒體庫路徑

穩定卡的頭像/立繪不走 Live2D（E4 未走），也不走宿主表情擴充套件當主鏈。卡內 `media_library.js` 管圖：分類、槽、變體、來源、氣泡裡怎麼用。

## 卡A 4.0.0 / 卡B同族

指令碼 id 仍叫 `crossed-zone-media-library`（同源元件）。

| 軸 | 值 |
|---|---|
| 型別 `ASSET_TYPES` | `bond` / `mecha` / `mothership` / `self` / `scene` |
| 槽 `ASSET_SLOTS` | `avatar`（頭像）/ `portrait`（立繪） |
| 羈絆變體 | `normal` / `nude` / `aftermath` |
| 來源 | 內建 catalog、`data-url`、`url-external` |

4.0.0 存檔上限 48M 字元；儲存時剝離內建資產回聲，只留玩家自己的圖。GIF ≤ 3M，單張 data URL ≤ 4M。頭像最長邊 256，立繪 1200。

內建圖用 `xy-builtin-media-assets` 段和 revision 號。本 Wiki 不搬 data URL。

## 誰在讀它

- 對話氣泡：`data-xy-dialog-avatar` → `resolveDialogMedia`
- 開局頁 / 控制中心：`data-xy-media-manager-*` 面板
- 卡B狀態列：`data-cz-media-*` 臨時切變體、開啟設定
- OMNI 掛載：同一檔案裡的 `renderOmniMounts`（媒體庫兼當樓內掛載器）

## 邊界

- E3 音訊/多模態、E4 Live2D：三張穩定卡主路徑未走。
- 外鏈 `url-external` 是玩家資源，不當作 AFV 真源，也不寫進 raw。
- 工坊釋出身份模板時要提示不可移植的本地媒體 key。
