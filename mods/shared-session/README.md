# shared-session

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。原版 README 見 [README.en.md](README.en.md)。

用連結或團隊共享 Claude Code 會話：隊友從自己的 Claude Code 加入並交談；一個會話完成工作，所有人即時看到每一輪，宿主機批准在其機器上執行的內容。

## 安裝

```
/plugin install shared-session@claude-code-mods-zh
```
