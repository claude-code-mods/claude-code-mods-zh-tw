# work-mode

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。

為 Claude Code 提供 `/work-mode` 會話模式：

- `auto`：不中途提問
- `out`：委派批次工作
- `wrap`：收斂並收尾

另外還提供一個委派提醒。

## 安裝

```
/plugin install work-mode@claude-code-mods-zh
```
