# Skins for Claude Code

> 繁體中文版由 claude-code-mods-zh-tw 專案翻譯，原作者與許可證見文末。原版 README 見 [README.en.md](README.en.md)。

為 Claude Code 的轉錄提供皮膚：帶圖示的工具行、diff、表格和 Mermaid 圖卡片、用量狀態帶，以及十五種主題。`/skin` 可即時切換。

## 安裝

```
/plugin install skins@claude-code-mods-zh
```

安裝後執行 `/skin` 選擇主題。
